# Privacidade

**O Capivara Rica não coleta nenhum dado.**

- Não há cadastro, login, nem conta.
- Não há anúncios, rastreadores, pixels, cookies de terceiros ou SDKs de redes sociais.
- Não há compras, moedas pagas nem caixas de recompensa.
- O progresso do jogo fica **só no seu aparelho** (IndexedDB/localStorage do navegador). Apagar
  os dados do site no navegador apaga o jogo salvo. Nada é enviado a servidor algum.
- O botão "Copiar resultado" gera um texto no seu aparelho; você decide se compartilha.
- O jogo é servido como site estático pela Cloudflare (Workers static assets). A Cloudflare registra, como
  qualquer servidor web, o endereço IP e o horário das requisições em logs técnicos próprios,
  sobre os quais este projeto não tem controle nem acesso. Não há Cloudflare Web Analytics,
  logs de Workers (observability desativada) nem qualquer outro contador ativado.

Este jogo é dirigido a crianças e adolescentes. Foi desenhado para que a LGPD (art. 14) e o ECA
Digital (Lei 15.211/2025) tenham o mínimo possível sobre o que incidir: a forma mais segura de
tratar dados de menores é não tratá-los.
