# Segurança / Security

O jogo é um site estático sem back-end, sem contas e sem coleta de dados. Ainda assim, se
você encontrar algo que permita executar código no aparelho de quem joga, vazar dados do
armazenamento local, ou qualquer outro problema de segurança, **não abra uma issue pública**:
escreva para **contato@capivararica.com.br**. Respondemos em até 7 dias.

The game is a static site with no back end, no accounts and no data collection. If you find
anything that allows code execution on a player's device, leaks local storage, or any other
security issue, **do not open a public issue**: e-mail **contato@capivararica.com.br**. We
answer within 7 days.
